# Production Control System (Backend)

Backend API для управления сменными заданиями на производстве с асинхронной обработкой задач, файловым хранилищем и внешними интеграциями.

## 🛠 Технологический стек

- **Язык:** Python 3.12+
- **Фреймворк:** FastAPI
- **ORM:** SQLAlchemy 2.0+ (async)
- **Валидация:** Pydantic v2
- **База данных:** PostgreSQL 16
- **Асинхронные задачи:** Celery 5.3+ + Celery Beat
- **Message Broker:** RabbitMQ
- **Кэш и Result Backend:** Redis 7+
- **Файловое хранилище:** SeaweedFS (S3-compatible, drop-in замена MinIO)
- **Инструменты:** Poetry, Ruff, MyPy (strict mode), Docker Compose

## 🚀 Быстрый старт

1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. Создайте файл `.env` на основе `.env.example` (при наличии).
3. Запустите инфраструктуру:

```bash
# Сборка и запуск всех сервисов в фоновом режиме
docker compose up --build -d

# Просмотр логов конкретного сервиса (например, api)
docker compose logs -f api
```

## Реализованный функционал

- S3 Хранилище: Интеграция с SeaweedFS для надежного хранения файлов импорта/экспорта/отчетов с генерацией presigned URL.
  Асинхронные задачи (Celery):
  Импорт партий из Excel/CSV с отслеживанием прогресса.
  Экспорт отфильтрованных партий в Excel/CSV.
  Массовая асинхронная агрегация продукции по уникальным кодам.
- Планировщик (Celery Beat):
  Автоматическое закрытие просроченных партий (ежедневно в 01:00).
  Очистка старых файлов из хранилища (ежедневно в 02:00).
  Обновление кэшированной статистики (каждые 5 минут).
